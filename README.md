# Догонялка

Приложение-трекер для учеников 100балльного: показывает, сколько вебинаров и заданий нужно
закрыть, чтобы догнать сегодняшний номер урока, и ведёт план на день.

**Открыть:** https://w1nday12.github.io/ege-plan/

## Как это работает

1. При первом запуске приложение просит токен личного кабинета lk.100points.ru.
2. Подтягивает список твоих курсов — выбираешь те, по которым хочешь догонять.
3. Показывает, до какого урока зачтено на сайте, — можно поправить под себя.
4. Считает: цель на сегодня (последний урок по расписанию), сколько осталось вебинаров
   и сколько заданий в их домашках, план на день.
5. Отмечаешь просмотренное — счётчики пересчитываются.
6. В настройках можно скачать `.ics` и добавить напоминания в календарь.

## Про токен

Токен **не хранится в репозитории** и не отправляется на сторонние серверы. Он лежит
только в localStorage браузера на устройстве пользователя и используется для запросов
к API 100points.ru. Отозвать можно, выйдя из аккаунта на всех устройствах.

Где взять: открыть lk.100points.ru → DevTools → Console → `copy(localStorage.getItem('token'))`.

## Приватность

В репозитории только код приложения. Данные о курсах, уроках и прогрессе хранятся
на устройстве пользователя.
