# ЕГЭ — догонялка

Мобильное приложение-трекер: показывает, какие вебинары нужно посмотреть, чтобы догнать
сегодняшний номер урока, и сколько заданий висит в домашках.

## Как пользоваться

1. Открой страницу на телефоне: https://w1nday12.github.io/ege-plan/
2. Меню Chrome ⋮ → «Добавить на главный экран» — появится иконка.
3. В настройках вставь токен из личного кабинета lk.100points.ru — приложение начнёт
   автоматически обновлять список уроков при каждом открытии.
4. Скачай `.ics` в настройках и добавь события в календарь — напоминания будут работать
   даже с закрытым приложением.

## Про токен

Токен **не хранится в этом репозитории и не передаётся на сервер**. Он сохраняется
только в localStorage браузера на устройстве пользователя и используется для запросов
к API 100points.ru. В любой момент его можно отозвать, выйдя из аккаунта на всех
устройствах, и вставить новый.

Взять токен: открыть lk.100points.ru, DevTools → Console → `localStorage.getItem('token')`.

## Данные

Список уроков, даты вебинаров и количество заданий подтягиваются из личного кабинета.
Данные о прогрессе (какие уроки просмотрены) хранятся только на устройстве.
